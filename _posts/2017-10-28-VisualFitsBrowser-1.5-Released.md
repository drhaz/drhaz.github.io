---
title: "VisualFitsBrowser Version 1.5 Released"
date: 2017-10-28
---

I have released a new version (1.5) of the VisualFitsBrowser. It has a few improvements that should be useful:
* Some documentation in the GitHub wiki page
* Support for sending multi-extension FITS files to ds9 as an IRAF mosaic.
* Support for sending several images to ds9. Just select several images in the table view and select File -> send all to ds9. All images will load, with frame, cmap etc locked between the frames. 
* If ds9 is not already running, double-click on the greyed out ds9 icon in the menu bar (right side). A new ds9 (if found) will be launched. 
* Updates in the code base to remove obsolete code.
* Initial (undocumented, experimental) support for wavefront analysis. 

The new version can be downloaded on [GitHub](https://github.com/drhaz/VisualFitsBrowser).  Please follow the instructions there.
